# Sitio Web de la Bolera

Este es el proyecto web estático para una bolera y centro de ocio. Ofrece información sobre las instalaciones, reservas, cumpleaños, eventos, carta del restaurante y zonas de juego.

## 🚀 Tecnologías

* **HTML5:** Estructura de las páginas.
* **CSS3:** Estilización y diseño responsivo.
* **JavaScript:** Interactividad básica en el frontend.

## 📁 Estructura del Proyecto

* `index.html`: Página principal de inicio.
* `/pages`: Contiene todas las páginas secundarias (`actividades.html`, `bowling.html`, `reserva-cumpleanos.html`, etc.).
* `/css`: Hojas de estilo (ej. `styles.css`).
* `/js`: Scripts del sitio web (ej. `main.js`).
* `/img`: Recursos gráficos y fotografías.

## 🛠️ Instalación y Uso

Al tratarse de un sitio web estático (HTML/CSS/JS puros), no requiere instalación de dependencias ni un servidor complejo para desarrollo.

1. Clona el repositorio:
   ```bash
   git clone <url-del-repositorio>
   ```
2. Descomprime o abre la carpeta del proyecto.
3. Abre el archivo `index.html` en tu navegador web favorito (Chrome, Firefox, Safari, Edge) o utiliza un servidor local como **Live Server** en VS Code para tener recarga automática durante el desarrollo.
