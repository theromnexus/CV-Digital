# Currículum Digital

Este es mi proyecto de Currículum Vitae interactivo en formato web. Muestra mi experiencia, proyectos, habilidades y diferentes secciones que reflejan mi trayectoria profesional de forma interactiva y dinámica.

## 🚀 Tecnologías

* **HTML5:** Estructura semántica de las páginas.
* **CSS3:** Estilización, maquetación y diseño responsivo adaptado a todos los dispositivos.
* **JavaScript:** Interactividad y dinamismo en el frontend.

## 📁 Estructura del Proyecto

* `index.html`: Página principal del currículum, resumen de perfil.
* `/pages`: Contiene todas las páginas o secciones adicionales del CV (experiencia, proyectos, contacto, etc.).
* `/css`: Hojas de estilo (ej. `styles.css`) y configuraciones de diseño.
* `/js`: Scripts del sitio web (ej. `main.js`) para interacciones de usuario.
* `/img`: Recursos gráficos, fotografías y elementos visuales del portfolio.

## 🛠️ Instalación y Uso

Al tratarse de un sitio web estático (HTML/CSS/JS puros), no requiere instalación de dependencias complejas.

1. Clona el repositorio:
   ```bash
   git clone https://github.com/theromnexus/CV-Digital.git
   ```
2. Descomprime o abre la carpeta del proyecto localmente.
3. Abre el archivo `index.html` en tu navegador web favorito (Chrome, Firefox, Safari, Edge) para ver el currículum de inmediato o utiliza la extensión **Live Server** en VS Code para visualización en vivo.
