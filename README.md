# 👨‍💻 Portfolio Web SPA - Brais Pérez Gómez

Bienvenido al repositorio de mi Currículum Vitae digital. Este proyecto es una **Single Page Application (SPA)** diseñada para presentar mi perfil profesional, proyectos y habilidades de forma interactiva, moderna y atractiva.

## 🚀 Tecnologías utilizadas
* **HTML5:** Estructura semántica de la página.
* **CSS3:** Diseño puramente responsivo (Grid/Flexbox), tipografía elegante y una paleta de colores cinematográfica.
* **JavaScript:** Interactividad, menú "sticky" adaptativo y seguimiento del usuario a lo largo de las distintas secciones.

## 🌐 Visualización en vivo
Puedes acceder al portfolio online funcional e interactivo alojado a través de GitHub Pages haciendo clic en el siguiente enlace:
👉 [**Visualizar CV Digital**](https://theromnexus.github.io/CV-Digital/)

## 📁 Estructura de archivos
* index.html: Contiene toda la información y secciones del currículum (Hero, Sobre mí, Experiencia, Formación, Proyectos interactivos con enlaces directos y Contacto).
* style.css: Define la personalidad visual y adaptabilidad a cualquier tamaño de pantalla.
* script.js: Añade dinamismo al entorno visual (transiciones del menú de navegación).
